Mitrawriter

An agentic desktop research environment for scientists. It reads your papers, writes with citations, connects your code to your results, and assembles slides and theses.

Public beta · December 2026

The problem

Research writing is scattered across a PDF reader, a reference manager, a LaTeX editor, a code repo, and a slide tool. Mitrawriter puts them in one place and gives an agent access to all of it.

What the agents do

  • Paper library with cross-paper chat: ask questions that span your whole library, not one PDF at a time.
  • Citation-aware LaTeX writing: drafting that stays grounded in the sources you actually have.
  • Code-to-paper integration: connects analysis code and results to the manuscript.
  • Slide and thesis assembly: turns existing work into presentations and long-form documents.

Architecture

Every workflow is built on a reusable retrieval-augmented generation (RAG) core, the same ingestion, chunking, embedding, and retrieval patterns I run in production at MyStudySidekick, extended with agent-driven orchestration.
