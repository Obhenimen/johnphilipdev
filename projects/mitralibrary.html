Mitra Library

One place for everything you read, learn and write. A free, local-first desktop app for master's students, PhD students and researchers: courses, papers and your thesis in one private library, with an AI that cites every answer and helps you write.

The problem

Research work is scattered across a PDF reader, a reference manager, Word or Overleaf, a code repo, course folders and a slide tool. Chat-with-PDF tools only see one file at a time and upload it to someone's cloud. Mitra Library puts all of it in one library on your own computer and gives an AI agent access to everything you have actually read.

What it does

  • One library for everything: PDFs, Word and PowerPoint files, web pages and YouTube videos, with text, figures and metadata extracted (OCR for scans) and a Zotero import. Reading-time colors show what you have and haven't read.
  • Ask with citations: chat with one paper, a selection, a folder, your drafts or the whole library. Every answer links to the page, timestamp or section it came from, and voice chat lets you talk with your papers.
  • Write in Word or LaTeX: a Word-style editor and a LaTeX editor on TeX Live, with an AI co-writer that drafts and rewrites from your library, cites only sources you have, and checks every citation. A Word add-in brings the same citations into Microsoft Word.
  • Courses: drop in a syllabus and slides to get flashcards, quizzes and answers that cite the exact slide.
  • Slides and code: AI-made slide decks from your papers, edited in the app and exported to PowerPoint; a code editor and terminal with a coding agent that writes up your methods from the code.
  • The whole degree: notes with linked pages, paper search, degree progress from first course to defense, and an AI-use record for honest disclosure.

Architecture

A Tauri 2 desktop app with a Rust workspace underneath and a React + TypeScript interface. Text extraction (PDFium), OCR, embeddings and hybrid search run locally: a 2,600-chunk library searches in about 5 ms, and papers never leave the computer. The agent acts only through a typed tool registry with confirmations and undo; users bring their own AI by signing in with ChatGPT, or through Codex, Claude Code or Cursor over an MCP server.

A Go server handles accounts, plans and optional paid sync. Sync is a change log with a deterministic merge, tested on thousands of randomized three-device runs, stored in Google Drive or Mitra Cloud. The same Rust core powers the iPhone, iPad and Android apps, with Apple Intelligence on the device.
