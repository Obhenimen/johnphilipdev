Animal Game

An animal quiz game that helps players discover nearly 500 animals they may never have heard of, from dinosaurs to deep-sea fish.

The idea

Learning animal names by flashcard is dull. The Animal Game turns it into a quiz: see a picture, name the animal, spell it, then try again against the clock.

What's inside

  • 495 animals in six categories: 157 mammals, 103 fish, 100 birds, 48 insects, 47 dinosaurs, and 40 reptiles and amphibians.
  • Six game modes per category: picture identification, name identification, and spelling, each with a timed version.
  • Runs on iPhone, iPad, and Android.

How I built it

Built and published under Poscholars, using the same mobile release pipeline.
